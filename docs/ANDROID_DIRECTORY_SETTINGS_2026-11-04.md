# Android 目录与阅读设置

2026-11-04。最新用户要求：章节目录恢复完整界面，设置保留半覆盖以便边读边调；修复设置下滑时偶尔在四分之一高度卡住的问题。本轮仅改 Android，覆盖上一轮目录半屏方案。

- 目录通过 MaterialPageRoute 打开完整页面，不再进入 ReaderDraggableSheet。保留返回按钮、当前章节自动定位、延迟创建列表行和选章返回值；关闭目录后仍回到原阅读页面。章节选中背景和 Ink 继续由各行 Material 裁剪，不恢复滚动时的紫色色块。
- 阅读设置顶部为固定的48dp横条区域，背景使用主题 surfaceContainerHigh。横条放在列表外，滚动设置后仍能随时上扫展开或下扫收起。只有一个横条，不继承外层主题的第二个 handle。
- Android 设置仅保留0.5/1.0两个停靠高度，外层 ModalBottomSheet 的 enableDrag 关闭，DraggableScrollableSheet 在最小高度不自行关闭。横条半屏下扫直接 pop，让路由负责唯一的收起动画；不再先缩小到0.35，然后开始第二段关闭。全屏下扫回半屏，轻扫上推到全屏，中途可反向接管。
- 内容正常滚动时不关闭面板；列表在顶部、面板在半屏时继续向下拖到触摸阈值才关闭。禁用有色 overscroll 绘制。原字号/行距/页边距修改和即时预览逻辑不变。
- iOS 原生 Form/sheet 配置、颜色、交互以及 Flutter fallback 均保留。没有新的 IPA，也不触发 iOS 构建。
