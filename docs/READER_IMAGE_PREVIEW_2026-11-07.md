# 阅读点击区与图片预览

2026-11-07。公开版本仍为 v1.2.2，Android 内部94，iOS 由设备预览工作流编号。

- iOS 阅读页左侧上一页、右侧下一页，中间区域切换菜单。之前单页把上方与左侧并列判断，导致右上方被识别为上一页。Android 的原有点击区和翻页动画保持。
- 图片预览不再使用贯穿屏幕的灰条。iOS 在关闭按钮和保存/导出组下使用项目已有原生玻璃组件；Android 使用 Material 3 主题色调图标按钮。两端保留独立关闭、保存相册、导出原图及辅助功能名称。
- 适屏、放大和平移时都用实际绘制位置判断点击。图片内部的黑色像素仍属图片。由 PhotoView 协调轻点、双击缩放与捏合拖动；只有点留白才退出预览。没有给原阅读页再发一次点击，也不改阅读进度。
- 原图片缓存、解码限制、失败重试、原图保存及导出路径不变。iOS 玻璃效果走已有 UIKit 实现，旧系统使用既有回退。

检查覆盖两端实际预览路由的点图、双击放大、平移、保存和导出按钮接线、留白返回；另用离线章节打开 iOS 竖屏阅读页，验证右上、左上和中间点击。Widget 检查不代表真机玻璃效果或相册权限已验收。
