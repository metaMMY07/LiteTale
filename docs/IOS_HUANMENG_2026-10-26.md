# iOS 幻梦轻小说直接接口接入

2026-10-26。版本保持1.1.0；iOS构建号由独立GitHub工作流递增，不修改Android构建号77。

## 改动

- iOS内置“幻梦轻小说”使用与本轮Android已验收相同的公开9.0 API、身份和模型，包括最新更新、分类、完结、搜索、详情、完整目录及正文。
- 将生产接线从隐藏WebKit会话改为独立匿名HTTP，iOS请求明确标识为LiteTale客户端，不伪装成Android浏览器。Android原请求头保持。
- 使用插件作者公开提供的接入配置，拒绝把接口密码错误公告当正文。没有读取、导出或混用其他书源账号、Cookie和登录信息。
- 保留9秒含排队预算、相同请求合并、串行间隔、响应尺寸、固定HTTPS来源及429退避；不在失败后自动换域名或换会话。
- 兼容原站将列表total返回为当前页数量的情况；续页须匹配页码，重复或超限仍会明确失败。
- 内置来源不再列出ESJ，保留旧ID和已保存内容。导入的旧幻梦规则仍是独立书源，不将其历史强行合并到 `hm:` 内置来源。
- iOS液态玻璃、系统配色、普通翻页和Apple Books交接均沿用前版，本次没有改变Android界面或已交付APK。

## 验证

本机以iOS请求头执行真实公开接口调用，首页20本、第二页20本、目标搜索1条、234章目录、首章411字符，约2796ms；相关38项测试通过。该结果是Windows上的iOS请求配置检查，不能当成iPhone或iPad实测。

独立iOS acceptance工作流新增显式联网用例：在真正的iOS模拟器中调用生产 `api.huanmengSource`，检查首页、续页、搜索、目录和正文，再生成不含正文的结果截图。失败不能记成成功。原有离线WebKit协议检查继续保留，分别标识，不代表生产运输仍走WebKit。

本机记录位于 `build/qa/ios-huanmeng-2026-10-26/`；云端构建提交、原生验收和最终IPA摘要在该目录的交付记录中补充。IPA仍为未签名设备包，使用原Apple账号及Bundle ID `io.github.metammy07.litetale` 侧载，以保留应用数据。

接口来源与Android现场研究见 [幻梦公开项目调研](research/HUANMENG_PUBLIC_SOURCE_2026-10-25.md)。本次不承诺原站所有下架或受限书籍均可读取。
