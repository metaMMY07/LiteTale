# 导入和管理书源

进入“我的 → 书源与账号 → 添加与管理书源”，选择“本地文件”或“链接导入”。链接应直接返回 JSON，网页分享页或跳转链接需要先取得实际 JSON 地址。

预览会逐项列出可用规则和失败原因。可以只勾选可用项；重复书源默认另存，也可以选择替换规则。同 ID 换成另一网站时需要另存，避免原书籍和阅读记录被关联到不同站点。

支持 LiteTale JSON v1 和阅读（Legado）JSON 的部分 CSS/JSON 规则；不支持的脚本、XPath 扩展、登录或加密规则会明确提示。现有文库8和轻书架账号仍在各自入口登录，规则书源首版用于公开阅读。

导入后可以选择使用、改名、启用/停用和移除规则。一次只展示一个来源；书架、搜索记录和阅读进度按稳定书源 ID 隔离。移除规则保留原阅读数据，重新导入同 ID、同站点的规则可以恢复关联。

可用示例为 [SF-lightnovel-example.json](book_sources/SF-lightnovel-example.json)。该示例与内置 SF 规则独立保存，用于演示本地导入；SF 使用公开目录逐页查找书名，VIP 或需要账号的章节不在此规则能力范围。

内置扩展来源：

- 哔哩轻小说：使用 `www.bilinovel.net` 原站的搜索表单、书目和目录，沿用独立 `bili:` ID。它与原有“轻小说百科”不同。部分网络上的目录和章节会被原站验证拦截；内置浏览器适配器不等于可导入的外部 JS 规则，也不把 GitHub 项目地址当成规则 JSON。
- SF 轻小说：公开目录、详情、目录和正文；查找为目录页内匹配。

0.1.19 按用户要求移除了内置读书之家和中文维基文库入口。已有阅读数据和规则 ID 关联保留；用户明确自行导入的规则不受内置入口移除影响。

文件不超过 2 MB，一次最多 100 个来源。规则网络读取有超时、响应大小、分页和跳转上限；不执行外部代码。实际内置定义见 `assets/book_sources/bundled.json`。
