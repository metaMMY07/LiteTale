# LiteTale 0.1.25+67

书架增加“本地书籍”：通过系统文件选择器导入 EPUB 2/3，保存封面、目录、正文和插图，支持离线重开。沿用自选字体、横屏双页与仿真翻页；本地阅读历史独立分类，同一文件不会重复导入，移除时保留原文件。

导入在后台校验转换一次，阅读直接使用私有章节文件和有界缓存。修复仿真翻页过早缓存插图造成留白的问题，首帧绘制完成后才交给原生翻页组件。研究、REA 与测试边界见 [整合记录](../qa/epub-local-2026-10/INTEGRATION.md)。

支持流式 EPUB，单文件最大 128 MB；DRM、固定版式、ZIP64 暂不支持，原书 CSS 不完整保留。
