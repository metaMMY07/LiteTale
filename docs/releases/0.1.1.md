# LiteTale 0.1.1

> **实验性功能提示：仿真翻页目前仍不稳定，可能出现卡顿、掉帧或响应延迟。可在阅读设置中关闭，并切回普通翻页。**

这版处理曲面翻页在新书首次打开时响应慢、快速连续点击偶尔错页的问题。首次页面位图仍在生成时，点击和横向滑动会立即显示目标正文；原生缓存就绪后继续使用有文字弯曲和不透明空白纸背的曲面翻页。移除了手势启动前额外等待，缩短点击触发间隔，并避免截图页变化时原生视图被意外重建、翻页通道失效。窗口旋转后会重新生成对应尺寸的位图。

Android 35 模拟器上的连续前后翻页测试通过；横屏拖动中途、纸背和完成翻页均已目视验收。曲面翻页仍可在阅读设置中开关，普通翻页方式不变。书源、主题、图标和全屏页面转场沿用 0.1.0。

## Android 安装包

普通 Android 手机和平板使用 arm64 包；x86_64 包用于 x86 模拟器。两个 APK 均以 `lib/main.dart` 为入口，版本号 `0.1.1+36`，分 ABI 的 Android versionCode 为 2036／4036。

GitHub Release 附带两个 APK、`SHA256SUMS.txt` 和 APK 校验报告。`flutter test --no-pub`：89 项通过、2 项可选联网测试跳过；相关 Dart 静态检查通过；Android profile 集成测试覆盖首次即时翻页和缓存就绪后的原生连续前后翻页。两个 APK 的签名、ZIP 完整性、ABI 和 16 KB 原生库对齐检查通过。x86_64 正式包已在 Android 35 模拟器覆盖安装并启动，系统报告 `0.1.1`／versionCode 4036，未见启动崩溃。

60 Hz 模拟器上的原生曲面绘制仍有明显丢帧，样本中位帧耗时 36 ms；尚未在 120 Hz 真机测量，不能据此宣称达到 120 FPS。后续需在实际手机或平板抓取 FrameTimeline 后继续针对绘制瓶颈优化。当前 APK 仍沿用项目调试证书签名，公开分发前需配置专用发布密钥。
