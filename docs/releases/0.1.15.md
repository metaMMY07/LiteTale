## 阅读体验

- 各书源独立保存登录状态、书架与阅读历史。文库8支持同站网页登录会话复用；站点验证或网络策略可能影响个别请求。
- 支持导入界面字体和阅读字体，深浅色主题、动态配色与多种应用图标配色。
- 支持平板横屏双页阅读、插图查看、进度保存，以及可选的仿真翻页效果。

APK 沿用 Android Debug 签名，适合直接安装以及从相同签名的 LiteTale 版本升级；目前不用于应用商店分发。
