# LiteTale 1.0.0 正式版

LiteTale 1.0.0 将在线轻小说书源与本地 EPUB 书库整合到同一阅读应用中，各书源的账号、书架和阅读进度分别保存。

## 主要功能

- 支持文库8、轻书架、哔哩轻小说、轻小说百科及兼容的自定义书源规则。
- 导入 EPUB 2/3 图文书离线阅读，保留常见原书 CSS 样式，跨章节连续翻页并记住本地阅读位置。
- 可分别选择软件界面字体与阅读字体；阅读器支持横屏双页、音量键翻页和多种纸张主题。
- 在线书源保留仿真翻页，本地 EPUB 使用普通翻页。
- 改善文库8书架和正文读取，合并重复请求、设置等待上限并遵循站点限流提示。
