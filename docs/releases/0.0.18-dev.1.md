# LiteTale 0.0.18-dev.1

本版用于 Android 多书源功能测试。

首次打开无需登录。进入“设置 → 书源与账号”，选择“文库8”或“轻书架”后登录对应账号。切换时保留两站的登录状态，重启后恢复上次选择。

轻书架使用原生邮箱/密码表单登录。书目、搜索、目录和阅读继续使用应用原有界面。

- 书源各自显示，搜索历史、收藏和阅读记录分别保存。
- 支持轻书架正文中的插图及专用字体。
- 保留壁纸取色、六种主题配色，以及上一版搜索和插图卡死修复。

轻书架收藏当前仅保存在本机；尚未接入云书架同步和授权离线下载。已使用用户授权的真实账号验证登录、搜索、正文专用字体、插图，以及切换书源和重启后继续访问。访问范围仍由对应账号权限决定。

手机通常安装 `arm64-v8a`；`x86_64` 用于对应架构模拟器。此版保留原包名和签名，可覆盖此前同签名安装包。版本代码高于 0.0.17，覆盖后不要通过卸载旧版来回退，以免丢失应用数据。

主工程：`D:\Projects\LiteTale`。C 盘旧目录保留作备份。构建与接手说明见 `docs/LUNA_HANDOFF_0.0.18.md`。
