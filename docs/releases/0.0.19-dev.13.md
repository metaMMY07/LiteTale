# LiteTale 0.0.19-dev.13

This prerelease adds an optional book-style page turn to the native reader. The page backside is blank and opaque. Dragging from different heights along the right edge changes the fold; release past the center to turn, or release before it to cancel. The feature is off by default, and the existing page-turn mode remains available. Landscape reading still uses a single-page layout, and the fold is a simplified 2D effect rather than a full mesh simulation.

The app icon and theme controls are updated, with wallpaper colors, presets, and a custom color choice. The shared Material loading indicator and horizontal full-screen route transitions remain in place. This build also includes the existing isolated Wenku8, LightNovelShelf, and LNovel source support.
