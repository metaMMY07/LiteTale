# LiteTale v0.0.15

基于 [niuhuan/wild](https://github.com/niuhuan/wild) 源代码开发的轻小说阅读器修改版。本次发布 Windows x64 免安装包。

## 本次更新

- 接入轻书架近期录入的公开书目，在应用内浏览更多书籍、详情和阅读页面。
- 轻书架书库、个人书架和详情页统一使用 LiteTale 的主题配色与霞鹜新致宋 Plus 字体。
- 优化轻书架详情封面尺寸、简介行距和页内返回操作；保留原站账号权限与正文阅读设置。
- 修复全屏推荐页右侧空列，分类、排行、搜索和书架采用自适应布局，改善封面缩放显示。
- 新书源独立加载并使用短期缓存，失败不影响原文库8推荐页。

轻书架与文库8账号不互通，详情和阅读仍遵循轻书架的登录及权限要求。本次没有新增社区、商城等原生功能。

## 下载与升级

下载 `LiteTale-v0.0.15-windows-x64.zip`，解压后运行 `LiteTale.exe`。内嵌网页需要 Microsoft Edge WebView2 Runtime。

从旧版升级时，请先关闭 LiteTale 并备份原程序目录，再将压缩包内容覆盖到原目录。保留原有账号数据库、下载、图片缓存和 WebView2 用户数据目录，不要删除它们。

发布包只包含程序、运行资源及许可说明，不包含个人账号、Cookie、书架数据库、阅读缓存或下载内容。可使用附件 `SHA256SUMS.txt` 校验压缩包。
