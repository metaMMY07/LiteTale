# LiteTale 0.1.3

发现页“推荐／分类／排行／全部”四个标签现在有实色主题底、圆角外边框和三条竖向分隔线；选中下划线留在边框内。顶部标签栏不使用毛玻璃。Android 右上角的搜索图标换为月亮／太阳快捷键，可立即切换并保存深浅色模式；原有搜索框仍可进入搜索页。0.1.2 的底部毛玻璃导航继续保留。

## Android 安装包

普通 Android 手机和平板使用 arm64 包；x86_64 包用于 x86 模拟器。两个 APK 均以 `lib/main.dart` 为入口，版本号 `0.1.3+38`，分 ABI 的 Android versionCode 为 2038／4038。

本地安装包和校验文件位于 `build/releases/0.1.3/`。`flutter test --no-pub` 为 89 项通过、2 项可选联网测试跳过；本次改动文件的 Dart 分析无新错误，仍有 4 条该文件原有警告。两个 APK 的版本、签名、ZIP 完整性、ABI 与 16 KB 原生库对齐检查通过。x86_64 正式包已在 Android 35 模拟器覆盖安装并启动，系统报告 `0.1.3`／versionCode 4038。竖屏浅色、深色及横屏标签布局已目视检查，分类标签可点击切换；搜索框打开搜索页、主题快捷键切换及重启后保留浅色设置均已验证。截图见 `docs/qa/0.1.3/`。

模拟器在最终包验收时无法解析 `lnovel.tw`，因此这次只验收了页面布局、标签切换、主题和搜索入口，未把当次联网书单加载计入通过项。当前 APK 仍沿用项目调试证书签名，公开分发前需配置专用发布密钥。
