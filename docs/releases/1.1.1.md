# LiteTale 1.1.1 正式版

2026-10-31 · Android build79 · iOS build21

## 更新内容

- 内置幻梦轻小说，优化发现页书源切换和各书源的原网站访问入口。
- 发现页切换已加载的分类或标签时保留页面内容和位置，减少重复读取。
- iOS 恢复原生液态玻璃选源菜单，当前书源网址与“打开原网站”显示在菜单下方。
- 延续 EPUB 本地阅读、书源隔离和阅读状态缓存等现有功能。

## 安装包

- Android ARM64 手机／平板：LiteTale-1.1.1+79-arm64-v8a.apk
- Android x86_64 模拟器：LiteTale-1.1.1+79-x86_64.apk
- iPhone／iPad：LiteTale-1.1.1-ios-21-unsigned.ipa

Android APK 沿用应用既有签名，可覆盖安装同签名版本；此包用于侧载，不是 Google Play 商店签名包。iOS IPA 未签名，需使用用户自己的侧载工具和 Apple ID 签名安装。
