# LiteTale 1.1.0 · iOS 书源导入

本次针对 iPhone / iPad；保留既有 iOS 配色、玻璃控件、普通翻页和 Apple Books EPUB 交接。Android 的界面和原有 Legado 导入子集不随本轮更改。

- 修正 iOS 文件选择器缺少 UTType 导致的本地 JSON 导入错误。文件大小与 UTF-8 / JSON 内容仍需通过校验。
- 本地文件、JSON 链接均先解析和预览，再由用户确认保存；不兼容项显示原因。替换保留书源身份、禁用状态与已有书籍关联，保存失败不替换旧配置。
- 增加可明确转换的 Legado HTML 规则：CSS 链式选择、结果索引、自身文本筛选、文本合并、限定正则清理、目录和正文分页。
- 支持用户提供的“幻梦轻小说”规则。该规则没有推荐入口，首页提供直接搜索按钮；原规则提取纯文本，不包含插图。可选分类脚本等限制在预览中显示。
- 只折叠已审阅的静态请求头和有限纯文本替换表达式，不运行通用 JavaScript / Java / 登录 / 加密脚本。每个导入站点的 Cookie 会话仅存内存、限定同源，不共享内置书源账号；限流尊重 Retry-After，不自动换域名或重试。

IPA 由 GitHub macOS / Xcode 工作流构建，版本来自 pubspec 的 1.1.0，CI 单独分配构建号。仍需在 Windows 上自行签名侧载。

原站公开搜索此前在 Windows 实测返回 HTTP 403。离线规则、导入流程和模拟器系统界面验收与网站实际联网可用性分别记录；本版不绕过站点限制，也不承诺兼容全部阅读源脚本。
