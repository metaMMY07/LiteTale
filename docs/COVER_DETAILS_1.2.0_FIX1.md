# LiteTale 1.2.0：通用详情页与封面加载

2026-11-02。Android 版本 1.2.0+83，iOS 内部版本由云端设备构建生成。包含此前 build82 的覆盖翻页、插图预览/保存、EPUB 批量导入与分类。

## 本轮行为

- Android 参考 Yomiru 的信息层次、分卷卡片和单本封面占位；卡片、按钮、封面占位跟随用户选择的主题色。恢复 1.0.0 的页面/卡片/搜索框色阶，保留后续形状与底部毛玻璃导航。
- iOS 参考 Novella 的封面头部、阅读主操作、封面首帧过渡；保留 LiteTale 系统配色、液态玻璃和选色能力。头部仅使用封面的小幅色调，不改全局主题。
- 详情为多书源共用布局，使用真实作者、状态、更新时间、标签、卷章数；无字段则不显示。不支持书评/作者搜索/下载的源不展示对应操作。不加入其他软件独有的关注、点赞或统计数据。
- 分卷可展开/收起，章节控件按需构建。开始阅读跳过空卷；继续阅读使用原有历史章节、页位置和 EPUB 文字锚点。保留原有书架、登录、文库8站点恢复、下载与 Apple Books 路由。
- 首页整页转圈不改。本轮动画只用于单本封面，不给阅读插图加动效。新图 200ms 原位显现，内存已解码/已显示图与减少动态效果直接显示，固定书封区域不跳动。失败可单图重试。
- 同一封面按显示宽度分桶解码，沿用带 source/revision/请求头的图片仓库；小预览由已读图片生成，或解码原站自带 BlurHash，不额外请求低清图。预览最多 256 项/8MiB、同时最多 2 项缩略工作、不积压源图片；显示记录最多 256 项。小预览为 RAM 缓存，不宣称所有书源均新增磁盘缓存。文库8原有磁盘缓存保留。
- 列表到详情使用有界标题/封面提示，不替代真实详情，也不更改路由参数或账号书源语义。旧书封的迟到帧、失败及色调不会影响新书或新账号会话。

## 实现入口

- `lib/widgets/book_cover_image.dart`：封面专用首帧、占位、尺寸分桶、重试、代数隔离。
- `lib/services/book_cover_preview.dart`：小预览、BlurHash、封面色调与显示记录的有界缓存。
- `lib/widgets/book_details_view.dart`：多源通用头部、阅读动作、简介、懒构建卷章。
- `lib/models/book_detail_hint.dart` 与两个书目卡片：点击书目时保留轻量提示。
- `lib/pages/novel/novel_info_page.dart`：接入共用视图，保留原业务行为。
- `lib/theme/material_you.dart`：恢复 Android 1.0.0 色阶，保留当前主题选色和 UI 几何。
